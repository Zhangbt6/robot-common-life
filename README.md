# 学会行动，如何共处？

从机器自主到人机共同生活。面向机器人研究与社会科学对话的静态分享网页。

页面包含报告主线、三组研究故事、授权情境切换、四个讨论问题、研究设想、题目比较、海报简介、时间安排、试讲稿与浏览器本地笔记。

直接打开 `index.html` 可阅读。完整剪贴板功能建议通过 HTTPS 的 GitHub Pages 使用。无需安装依赖；不收集访客数据；笔记仅保存在当前浏览器。

## 内容边界

根据提供的分享草稿整理，未独立核验论文与实验记录。社会情境与共处实验为讨论或未来研究设想。正式分享前需补充经核验且获准公开的研究视频、图示及学术引用。页面不包含未公开论文或原始实验材料。

## 发布

GitHub Pages：从 `main` 分支根目录发布。源文件为 `index.html`、`style.css` 与 `app.js`。
