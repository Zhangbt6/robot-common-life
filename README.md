# 硅基的我们？

从具身智能到社会共处。以普通研究者的实验、阅读和疑问为起点的静态分享网页。2026-10-15 加入公开研究图像和演示，调整为务实、开放的交流语气。

主线：预测动作后果 → 从尝试中学习 → 社会具身（行为、关系、规则）→ 结尾回望人的经验与自身的延伸。社会具身是主体，关于“我们”的猜想放在其后留白。新增服务大厅的多方视角互动与交叉研究问题。包含来源卡片、思想实验、海报简介、24 页故事板、试讲稿与浏览器本地笔记。

## 图像与演示

图像及视频从原作者站点加载，不在本仓库转载媒体文件。Genie 3 视频来自 Google DeepMind；AgentGarten 视频和架构图来自 MirroS Team；Emo 图片和视频来自 Creative Machines Lab / Columbia Engineering。每个媒体区注明来源与观察线索。视频不自动播放；Emo 点击后才加载 YouTube 隐私增强播放器。远程资源不可用时保留出处链接与提示。

直接打开 `index.html` 可阅读。完整剪贴板功能建议通过 HTTPS 的 GitHub Pages 使用。无需安装依赖；不收集访客数据；笔记仅保存在当前浏览器。

## 内容边界

外部研究依据原始论文及作者机构资料核查，正文附出处与证据边界；HERA 项目全文访问受限，摘要可检索，页面已标明。讲者哲学立场与思想实验分别标注。个人研究仍依据提供的草稿，未核验原始实验记录，视频尚未导入。页面不包含未公开论文或原始实验材料。
