# 硅基的我们？——从自主行动到社会共处

政务学院分享的配套网页：主讲约 30 分钟，交流约 15 分钟。网页既是听众可以读的版本，也是讲者的备讲台和之后做 PPT 的底稿。

线上地址：https://zhangbt6.github.io/robot-common-life/

## 主线

明线是具体的：机器人怎样向人学习（动作、知识、情绪，再自己练），走进社会的两道坎（身体撑不住、读不懂人），以及留给治理的三个问题（基础设施、公共空间、家庭数据）。

暗线是讲者的哲学理解：DNA 传下身体，文化传下知识，现在人把经验直接写进硅基的身体。暗线在页面上用紫色竖线标出，只在开场、每段结尾和结尾出现。

完整的设计理由见 `docs/主线方案-v3.md`，事实核查和来源见 `research.html`。

## 视觉

碳与硅：封面用元素周期表第 14 族的碳（6）和硅（14）做标志。冷灰纸面 `#EEF0F0`，石墨墨色 `#23262B`，硅片蓝紫 `#4A3F9F` 是唯一的强调色。标题和讲述性文字用朱雀仿宋（以 1932 年“南宋”活字为蓝本的开源仿宋），正文用系统黑体。

## 文件

- `index.html`：分享页，含备讲台（简介、时间表、16 页故事板、关键转场、笔记）
- `research.html`：主线依据、事实核查、讲法分寸、来源索引
- `site.css`、`app.js`：样式和交互，无外部依赖
- `fonts/`：朱雀仿宋子集与 SIL OFL 1.1 许可证
- `tools/subset_font.py`：改了页面文字后重新生成字体子集
- `archive/2026-10-16/`：上一版（六章、53 分钟）的完整页面
- `docs/`：主线方案文档

## 使用

直接打开 `index.html` 可以阅读，复制功能需要在 HTTPS 的线上页面使用。点“展示模式”后，用左右方向键逐段切换，Esc 退出；展示模式会隐藏导航、讲者备注和备讲台。

研究视频和图片从原作者站点加载，仓库里不存媒体文件。视频不自动播放，Emo 的 YouTube 视频点击后才加载。国内网络可能打不开 YouTube 和 Google 的媒体，上台前要在现场测试，必要时提前下载到本地并保留出处。

备讲笔记只存在当前浏览器（与上一版共用同一存储键），可以导出成文本。网页不收集访客数据。

## 改了文字之后

页面文字变动后，新出现的汉字如果不在字体子集里，会退回系统仿宋。重新生成子集：

```
pip install fonttools brotli
python tools/subset_font.py 下载的/ZhuqueFangsong-Regular.ttf
```
