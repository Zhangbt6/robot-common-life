# 硅基的我们？

从自主行动到社会共处。以普通研究者的实验、阅读和疑问为起点的静态分享网页。2026-10-15 加入公开研究图像和演示，调整为务实、开放的交流语气。

主线：自主机器人 → 世界模型与预测边界 → 模拟环境中的探索和自我改进 → 手的适配、全身协调与面部回应 → 社会具身与共处 → 结尾回望我们自己。个人研究作为短插入。包含海报简介、53 分钟分享 + 7 分钟讨论、28 页故事板、讲稿和独立 research.html 调研依据页。

## 图像与演示

图像及视频从原作者站点加载，不在本仓库转载媒体文件。Genie 3 视频来自 Google DeepMind；AgentGarten 视频和架构图来自 MirroS Team；Emo 图片和视频来自 Creative Machines Lab / Columbia Engineering。新增 DexUMI 灵巧手与 ASAP 全身运动的原站视频，以及 Gemini Robotics 1.5 官方图像。每个媒体区注明来源与观察线索。视频不自动播放；Emo 点击后才加载 YouTube 隐私增强播放器。远程资源不可用时保留出处链接与提示。

直接打开 `index.html` 可阅读。完整剪贴板功能建议通过 HTTPS 的 GitHub Pages 使用。无需安装依赖；不收集访客数据；笔记仅保存在当前浏览器。

## 内容边界

外部研究依据原始论文及作者机构资料核查，正文附出处与证据边界；HERA 已补入具名期刊论文、DOI 与机构书目，核查限于摘要与书目信息。讲者哲学立场与思想实验分别标注。个人研究仍依据提供的草稿，未核验原始实验记录，视频尚未导入。页面不包含未公开论文或原始实验材料。

## 发布

GitHub Pages：从 `main` 分支根目录发布。源文件为 `index.html`、`style.css`、`narrative.css`、`app.js` 与 `research.html`。上一版保存在 Git 历史，笔记沿用同一浏览器存储键。

## 2026-10-16 定稿设计

首页和复制区统一为已提交的 100 字简介；移除备选题目选择。新增六章节导览、演示索引、阅读进度与展示模式章节切换（左右键，Esc 退出）。沿用纸色、深绿和暖橙；个人研究接入笔记可展开。`edition.css` 统一封面、媒体、手机布局与打印样式。
