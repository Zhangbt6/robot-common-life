# 我们在创造谁？

机器人的认知、成长与共处。面向机器人研究、认知与社会科学对话的静态分享网页。2026-10-15 更新为三幕叙事。

主线：我们给它经验 → 它获得自己的经历 → 它走向我们。世界模型、自我改进与社会具身分别进入预测、成长与共处三幕；自己的研究融入各幕。包含来源卡片、思想实验、海报简介、24 页故事板、试讲稿与浏览器本地笔记。

直接打开 `index.html` 可阅读。完整剪贴板功能建议通过 HTTPS 的 GitHub Pages 使用。无需安装依赖；不收集访客数据；笔记仅保存在当前浏览器。

## 内容边界

外部研究依据原始论文及作者机构资料核查，正文附出处与证据边界；HERA 项目全文访问受限，摘要可检索，页面已标明。讲者哲学立场与思想实验分别标注。个人研究仍依据提供的草稿，未核验原始实验记录，视频尚未导入。页面不包含未公开论文或原始实验材料。

## 发布

GitHub Pages：从 `main` 分支根目录发布。源文件为 `index.html`、`style.css`、`narrative.css` 与 `app.js`。上一版保存在 Git 历史，笔记沿用同一浏览器存储键。
