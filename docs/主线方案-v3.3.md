## 为什么这样改

**开场不讲个人经历。** 开场的任务是抛出伏笔问题，胡宇航从厦门到首形科技的经历和这个问题关系不大，还会占掉一分多钟。现在用“同一张脸，两年从实验室走进人群”这个现象来开场，再点出三样从人身上学来的本事。原理留到第一段讲，开场只提问题。

**第一段以“向人学三样”为主线。** 这是讲者最初的思路：机器人向人学习知识、动作和情绪。大脑/小脑是帮助理解的工程分工，只在总览里做一行对应：知识像大脑，动作像小脑，情绪两边都要用。harness 只用来说明“知识和动作怎样配合”。

**学情绪放在最后。** 这样能回扣开场那个笑容，并用“表情像人，不代表感受像人”给第三段的“读不懂人”埋下伏笔。
